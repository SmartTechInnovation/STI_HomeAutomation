# 3.6: `ProjectValidator`: references, types and cycle warnings

**Story ID:** 3.6  
**Epic:** 3 — Wiring and validation in the editor  
**Slug:** project-validator  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **an integrator**,  
I want **a list of problems in my project before I save or upload it**,  
so that **I fix mistakes in the editor instead of discovering them on the controller**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `ProjectValidator_class::run(project)` returns a list of findings `{severity (Error|Warning), code, iUuid, message}`.
2. **Errors:** a `Ref` or `Io` that points to nothing; a `Source` whose type fails `canConnect`; a `BlockInstance` whose type is unknown.
3. **Warnings:** cycles in the wiring (e.g. A → B → A), listing every instance in the cycle; an unconnected required input.
4. The validator runs on save (findings shown; save not blocked) and before upload (Errors block the upload).
5. Findings are shown in a list (`LogTab` or a panel); clicking one selects the instance on its page.

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- `ProjectValidator_class` (new): type checks, unresolved references, cycle **warnings**, and `Requires` regeneration; used by save and by upload. [Source: architecture.md#component-project-l2]
- Recursion is not forbidden: the editor finds cycles in the wiring and shows a warning on the instances involved; upload is still allowed. [Source: architecture.md#adr-005]
- The editor validates the same reference rules as the runtime loader, so problems are caught early. [Source: architecture.md#adr-005]
- Findings go to the `LogTab` surface, not modal dialogs. [Source: architecture.md#adr-010]
- Requires regeneration is already done in 2.4; the validator just reports a mismatch. [Inference]
