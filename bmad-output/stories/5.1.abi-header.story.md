# 5.1: `sdk/stix_abi.h`: the plugin C ABI v1

**Story ID:** 5.1  
**Epic:** 5 — Plugin SDK and C ABI  
**Slug:** abi-header  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **a block or driver author**,  
I want **one stable C header that defines everything my plugin exchanges with the runtime**,  
so that **my plugin works with any compiler and keeps working across runtime releases**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `sdk/stix_abi.h` (MIT licence header, C99, `extern "C"` guards) defines `STIX_ABI_MAJOR 1` / `STIX_ABI_MINOR 0`, `stix_type`, the 16-byte `stix_value`, `stix_source_id`, `stix_bind_info`, `stix_host` and `stix_plugin_v1` exactly as architecture §6.2 (including `emit_signal`, `set_property` and `on_property`).
2. `static_assert`/`_Static_assert` checks: `sizeof(stix_value) == 16`, plus the field offsets.
3. The header compiles cleanly as C (gcc/clang `-std=c99 -Wall -Wextra -pedantic`) and as C++17.
4. Each function pointer has a comment stating which thread may call it and that callbacks must not block.
5. A CTest target compiles a tiny C plugin and a tiny C++ plugin against the header.

## Tasks / Subtasks

- [ ] Write the header from §6.2 (AC: #1, #4)
- [ ] Size and offset asserts (AC: #2)
- [ ] Compile tests (C and C++) (AC: #3, #5)

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- The ABI sketch (value types, `stix_bind_info`, `stix_host` with `emit`, `emit_signal`, `set_property`, `source_name`, `now_us`, `log`; `stix_plugin_v1` with `create`, `destroy`, `bind`, `on_input`, `run`, `on_property`, `open`, `close`, `write`) is the contract. [Source: architecture.md#6-2-plugin-c-abi-v1]
- Every plugin exports one symbol `extern "C" const stix_plugin_v1* stix_plugin_entry(void);`; no C++ types, exceptions or STL containers cross the boundary; `abi_version` is checked on load. [Source: architecture.md#adr-006]
- Threading: all host functions are safe from any thread; one instance is never entered by two threads at once; `write` must be thread-safe and non-blocking; callbacks return quickly. [Source: architecture.md#adr-005]
- The source is a numeric `SourceId`, not a string. [Source: architecture.md#adr-006]
- The SDK headers are MIT. [Source: architecture.md#adr-014]

## Testing
