# 10.10: Monitoring: symbols, `Subscribe`, `ValueBatch`, force, variables

**Story ID:** 10.10  
**Epic:** 10 — STIx Runtime MVP (separate repository `stix-runtime`)  
**Slug:** monitoring-server  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **an integrator**,  
I want **live values and the ability to force signals**,  
so that **I can debug the installation in real time**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `GetSymbols` returns the symbol table from 10.4 with the project hash.
2. `Subscribe {slots, periodMs}` → `ValueBatch` at most every `periodMs` (default 50) with only the changed slots; idle projects send nothing.
3. `Force {slot, value, persistent}` / `Release` apply through `emit_signal` from the RuntimeManager; forces are recorded in the audit log and released on disconnect unless persistent.
4. `SetVariable {slot, value}` works the same way.
5. Monitoring costs < 5 % CPU with 500 subscribed slots changing at 10 Hz on the reference target.

## Tasks / Subtasks

- [ ] GetSymbols (AC: #1)
- [ ] Change tracking + batches (AC: #2, #5)
- [ ] Force/Release + audit log (AC: #3)
- [ ] SetVariable (AC: #4)
- [ ] CPU measurement (AC: #5)

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- `ValueBatch` at most every 50 ms with only the slots that changed since the last batch, `[slot, value, ts]`; bandwidth and CPU proportional to change. [Source: architecture.md#adr-007]
- The RuntimeManager applies values from STIx Config (Force, SetVariable) with the same `emit_signal`. [Source: architecture.md#adr-005]
- Forced values are flagged in the audit log and released on disconnect unless persistent. [Source: architecture.md#adr-008]
- NFR-09 target: monitoring < 5 % controller CPU. [Source: architecture.md#0-requirements-baseline]
