# 4.1: Package `manifest.xml` and descriptor v1 attributes

**Story ID:** 4.1  
**Epic:** 4 — Library packages and catalogue (editor)  
**Slug:** manifest-and-descriptor-v1  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **a block author**,  
I want **a documented package manifest and descriptor format that the editor reads**,  
so that **my package declares its identity, version, ABI, targets, tick period and UI once**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. `docs/formats/package-v1.md` specifies `manifest.xml`: root `Package` with `Uuid`, `Name`, `Kind` (Block|Periphery|Protocol), `Vers` (SemVer), `AbiVersion`, `Licence`, and children `Target Triple="linux-aarch64"` … and optional `Ui Tile=… Detail=… ApiVersion=…`.
2. A `PackageManifest_s` parser reads and validates it (missing Uuid/Vers/Kind → error naming the field).
3. `BlockManager` reads the new descriptor attributes: block root `TickMs` (default 0), port and property `Ui` (`Read|Write|ReadWrite`, default none); `BlockType_s` and `PortDefinition_s` hold them.
4. Every folder in `templates/blocks/**` and `templates/periphery/**` that is a package gets a `manifest.xml`, so the templates are valid development packages.
5. Unit tests cover the manifest parser and the new descriptor fields.

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- Package layout: `manifest.xml` (identity, kind, ABI, targets, licence, dependencies), `Descriptor.xml`, `icon.svg`, `docs/`, `ui/Tile.qml`, `ui/Detail.qml` (optional, ADR-015), `lib/<target>/libstix_<name>.so`, `SIGNATURE`. [Source: architecture.md#adr-004]
- `manifest.xml` declares `AbiVersion` and the supported `Target` triples; the root of a block's `Descriptor.xml` declares `TickMs` (0 = never ticked). [Source: architecture.md#adr-004] [Source: architecture.md#adr-005]
- Ports and parameters carry `Ui="Read"|"Write"|"ReadWrite"` (default: not visible to the HMI); the descriptor declares `<Ui Tile=… Detail=… ApiVersion="1.0"/>`. [Source: architecture.md#adr-015]
- During the MVP the existing `templates/` folders are treated as **unsigned development packages**, with `Vers` normalised to `x.y.0`. [Source: architecture.md#adr-004]
- Licence is declared in `manifest.xml`. [Source: architecture.md#adr-014]
