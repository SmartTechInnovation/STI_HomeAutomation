# 6.7: Upload and download the project (with `baseRev`)

**Story ID:** 6.7  
**Epic:** 6 — Controller connection (editor side)  
**Slug:** upload-download  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **an integrator**,  
I want **to upload my project to the controller and download it back**,  
so that **the controller runs my program, which restarts only on upload**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. Upload: runs `ProjectValidator` (Errors block the upload), saves the project, sends `UploadProject` chunked with `{sha256, baseRev}`, and shows progress; on `{ok, rev}` it stores `BaseRev = rev` (2.5).
2. On `RevConflict {rev}`, upload stops and emits `revConflict(rev)` for the merge flow (9.3); nothing is overwritten.
3. On `Error {loadErrors[]}`, the controller's load errors are listed in `LogTab`, linked to the instances by `IUuid`.
4. Download: `DownloadProject` opens the controller's project in a new tab (or replaces the open one after confirmation) and sets `BaseRev` to its `Rev`.
5. "Activate previous" sends `ActivatePrevious` after a confirmation.
6. There is no Start/Stop anywhere in the UI.

## Tasks / Subtasks

- [ ] Top-bar buttons, role-gated (AC: #1, #4, #5, #6)

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- FR-09: the program runs all the time; no start or stop; it restarts only when a new project is uploaded (atomic swap). [Source: architecture.md#0-requirements-baseline] [Source: architecture.md#adr-005]
- `UploadProject` carries `{sha256, baseRev, force}` → `{ok, rev, symbolTable}`, `RevConflict{rev}` or `Error{loadErrors[]}`; `ActivatePrevious` re-deploys the kept previous project. [Source: architecture.md#6-1-stix-link-messages-protocol-v1]
- An upload never overwrites changes on the controller without the engineer choosing Overwrite or Merge. [Source: architecture.md#adr-017]
- The validator runs before upload and Errors block it. [Source: architecture.md#component-project-l2]
- The dependency check (`CheckProject`) is added in 8.4; this story uploads directly. [Inference] [Source: epics.md#epic-8]
