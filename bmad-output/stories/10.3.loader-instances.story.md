# 10.3: Loader: XML → object instances with their XML-node pointers

**Story ID:** 10.3  
**Epic:** 10 — STIx Runtime MVP (separate repository `stix-runtime`)  
**Slug:** loader-instances  
**Status:** ready-for-dev   <!-- lifecycle: backlog -> ready-for-dev -> in-progress -> review -> done -->

> Owned by planning until `ready-for-dev`. Sized to one dev-day (~2-8h). No story points.

## Story

As **the controller**,  
I want **to turn the project XML into one object instance per block, protocol and driver**,  
so that **each instance runs with its own parameters and local state**.

## Acceptance Criteria

<!-- LOCKED. Numbered, testable. External dev tools must not edit. -->

1. The loader parses `Project.xml` with pugixml, checks every `Requires` entry against the package store (missing or different Sha256 → load error naming it), and `dlopen`s each required plugin, checking `abi_major`.
2. It calls `create` once per `BlockInstance` and per configured periphery/protocol node, passing that element's parameters (`Property` values) in descriptor order.
3. Every instance stores a pointer to its own XML node; a hash map `IUuid → instance` is built.
4. Any load error returns a structured list `{iUuid, code, message}`; nothing partial keeps running.
5. The parsed document stays in memory (used later only for saving parameter changes).

## Tasks / Subtasks

- [ ] Parse + Requires check (AC: #1, #4)
- [ ] dlopen + entry + ABI check (AC: #1)
- [ ] Instance creation with parameters (AC: #2)
- [ ] Node pointers + IUuid map (AC: #3, #5)
- [ ] Error list (AC: #4)

## Dev Notes

<!-- LOCKED. Cited guidance. [Inference] marks judgement calls not stated in the planning docs. -->

- Startup order: extract instances as objects → load each instance's parameters from its XML element → connect its callbacks; afterwards the fast path never reads the XML. [Source: architecture.md#1-system-overview] [Source: architecture.md#adr-005]
- `create` one instance per `BlockInstance` and per configured periphery or protocol node (e.g. each Modbus TCP connection); a node's channels are that instance's signals. [Source: architecture.md#adr-005]
- Each instance gets a pointer to its own XML element (pugixml node) and the runtime builds a hash map `IUuid → instance`. [Source: architecture.md#adr-017]
- Plugin entry `stix_plugin_entry`; reject a MAJOR ABI mismatch with a clear error; property index = element order in `Descriptor.xml`. [Source: architecture.md#adr-006]
- If loading fails, the old project keeps running (handled in 10.9). [Source: architecture.md#adr-005]
